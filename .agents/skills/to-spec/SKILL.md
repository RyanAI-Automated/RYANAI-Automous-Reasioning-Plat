# To spec
Synthesize existing conversation and repository evidence; do not restart the interview. Produce problem, users, current behavior, goals, non-goals, constraints, domain terms, interfaces, data/security impact, acceptance criteria, test plan, rollout and rollback. Mark assumptions and unresolved owner decisions. Publish to a tracker only when authorized; otherwise save as a repo document/PR artifact.
