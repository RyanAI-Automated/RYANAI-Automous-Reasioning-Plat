# Domain modeling
Extract nouns, roles, events, states and invariants from code and user language. Identify overloaded terms and competing names. Stress-test the model with normal, failure, concurrency and permission scenarios. Update the glossary/ADR only when the definition is durable; use the same terms in API, schema, UI and tests.
