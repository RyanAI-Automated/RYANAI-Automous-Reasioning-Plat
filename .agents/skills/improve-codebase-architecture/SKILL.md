# Improve codebase architecture
Survey a bounded area: identify change hotspots, coupling, duplicated policy, unclear ownership and test seams. Rank opportunities by user impact, risk and cost. Present evidence and one recommended seam. Grill only the selected change's material decisions, write an ADR/spec, and implement only after approval. Avoid broad rewrites and speculative abstractions.
