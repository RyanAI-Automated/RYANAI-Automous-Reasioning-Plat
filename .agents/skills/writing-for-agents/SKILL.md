# Writing for agents
Put stable rules in the highest-level discoverable instruction file and task-specific guidance in a scoped skill. Use imperative language, define terms, specify inputs/outputs and failure behavior, and link rather than duplicate long documents. Keep instructions testable and avoid contradictory or overly broad mandates. Never place secrets or personal data in agent instructions.
