# Triage
For each issue capture impact, severity, reproducibility, affected version, owner, dependencies and evidence. Move it through proposed → accepted → ready → in progress → review → done (or blocked/declined). Define entry/exit criteria for each state. Never mark done without acceptance evidence; do not invent labels or alter project tracker configuration without approval.
